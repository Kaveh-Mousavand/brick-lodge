# Contributing to Brick Lodge

Thank you for your interest. Contributions are welcome — please get in touch with the maintainer,
Kaveh Mousavand (kaveh.mousavand@oist.jp), before starting on a substantial addition.

## Workflow

1. Work on a **branch**; never push to `main` directly (it is protected).
2. Open a **pull request** with a short description of what you changed and why.
3. The maintainer reviews every pull request. Changes go live only after approval and merge.

## Content guidelines

* **Be precise and sourced.** State the setting and hypotheses of every conjecture or question,
  and give the first appearance (with arXiv number) and the published version, if any.
* **Hyperlink every reference** (arXiv abs page, journal page).
* **Chronological order.** Conjectures and questions are listed by date of first appearance
  (arXiv date, or thesis date where there is no arXiv preprint).
* **Say what is known.** In each "More information" drop-down, separate background, current
  state, and connections to other conjectures; do not overstate partial results.
* **Keep changes focused.** One topic per pull request makes review easier.
* Edit only the files in this repository; keep the existing page structure and styling.
